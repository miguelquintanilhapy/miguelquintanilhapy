## Featured Projects

### [SquadBuilder](https://github.com/miguelquintanilhapy/squad-builder)
AI copilot that helps founders and CTOs size software engineering squads, with cost, timeline, and risk estimates.

- **The AI never does the math:** cost, timeline, and risk come from a deterministic TypeScript engine; the LLM only interprets the input and narrates the result
- Validates the structured JSON returned by the model with **Zod** and exposes three internal API routes (analyze, recompute, negotiate)
- Natural-language negotiation with a trail of comparable scenario versions, covered by **Vitest** tests

`TypeScript` `Next.js` `React` `Tailwind` `Gemini`

### [SAD Precificação](https://github.com/miguelquintanilhapy/sad-precificacao)
Desktop system for quotes and project management, with a financial dashboard and PDF commercial proposals. Capstone project of my technical course in IT.

- **Data integrity at the repository layer**, not just the UI: blocks deletion of records in use, checks duplicates, and protects the last active administrator
- **User-friendly error handling:** plain messages on screen, technical detail in a local log with masked credentials
- MVVM architecture, hashed passwords with login throttling, and PDF proposals generated with QuestPDF

`C#` `.NET` `WPF` `MVVM` `MySQL`

### [Climate Monitoring](https://github.com/miguelquintanilhapy/Climate-Monitoring)
Real-time weather monitoring web app. Built at the **1st Univap Informática Hackathon 2025**.

- User registration, saved cities, and weather alerts by location

`TypeScript` `React` `Node.js` `Express` `MongoDB`
