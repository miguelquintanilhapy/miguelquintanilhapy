### 🚀 Projetos em destaque

**[SquadBuilder](https://github.com/miguelquintanilhapy/squad-builder)**
Copiloto com IA que ajuda founders, CTOs e PMs a dimensionar squads de engenharia: analisa o escopo do projeto e gera composições de equipe com estimativas de custo, prazo e risco.
`TypeScript` `Next.js` `React` `IA`

**[SAD Precificação](https://github.com/miguelquintanilhapy/sad-precificacao)**
Sistema desktop (WPF/.NET) para gestão de orçamentos, projetos, clientes e custos, com dashboard financeiro e relatórios em PDF.
`C#` `.NET` `WPF` `MVVM` `MySQL`

**[Climate Monitoring](https://github.com/miguelquintanilhapy/Climate-Monitoring)**
Aplicação web de monitoramento climático em tempo real por localização, com cadastro de usuários, cidades salvas e alertas meteorológicos. Desenvolvido no 1º Hackathon Univap Informática 2025.
`TypeScript` `React` `Node.js` `Express` `MongoDB`
